재처리는 기존 검증기를 그대로 적용한다. 저장된 완료 단계는 재사용해 기존 단계 전환을 보존하고, 실패한 마지막 단계 또는 결과 미확인 단계만 교체한다. 이후 필요한 상위 단계는 원래 정책을 따른다. 모델은 luna medium → 6.1 sol medium → 6.1 sol high, 문항 동시 처리 3개, ChatGPT 구독 로그인만 사용한다. 단계별 새 호출 최대 1회, 승인 상한 261회이며 조기 성공하면 다음 단계를 호출하지 않는다. 성공 문항 ID 차단, 입력·원래 결과 해시, 회차별 호출 예약, 영구 시작 기록과 프로세스 잠금으로 중복 호출을 막는다. 실패는 실제 오류와 함께 기록하고 다음 문항으로 넘어간다. 자동 반복 회차는 없다.
