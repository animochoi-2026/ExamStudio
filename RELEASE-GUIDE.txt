업데이트: 오른쪽 AI 설정 아래 프로그램 업데이트에서 최근 정식 배포 3개를
버전 번호로 선택합니다. 현재보다 낮은 버전은 롤백, 같은 버전은 재설치합니다.
목록과 현재 설치 버전에 속하지 않는 로컬 업데이트 ZIP·백업은 자동 정리합니다.
작업 데이터·결과물·설치 실패 복구 파일은 삭제하지 않습니다.
GitHub는 최근 정식 버전 3개만 보관하고 더 오래된 릴리즈·첨부 파일·태그를 자동 정리합니다.

지원 환경: Windows 10/11 64비트 (x64). macOS/ARM 전용 배포판은 아닙니다.

1. ZIP 파일을 다운로드한 뒤 폴더 전체의 압축을 풀어 주세요.
2. 바탕화면·문서 등 쓰기 가능한 폴더에 두고 문제공방.exe를 실행하세요.
   ZIP 안에서 바로 실행하거나 exe 파일만 따로 복사하지 마세요.
3. 사용할 AI를 선택하고 본인 계정으로 로그인하세요.
   Claude: 오른쪽 Claude 로그인·계정에서 로그인하세요. 처음 연결할 때 공식
   Claude Code CLI를 내려받아 무결성을 검증합니다. 별도 앱 설치는 필요 없습니다.
   콘솔과 브라우저에서 로그인을 마친 뒤 연결 확인을 누르세요.
   Sonnet·Opus와 추론 수준을 선택할 수 있으며 기본값은 Sonnet·보통입니다.
   Claude Code를 사용할 수 있는 구독 계정이 필요하며 API 키로 전환하지 않습니다.
   GPT: 필요한 Codex 실행 파일이 포함되어 있습니다. 별도 Codex/Node.js 설치 없이
   문제공방의 GPT 로그인·계정에서 본인의 ChatGPT 계정으로 로그인하세요.
   인터넷 연결 및 해당 계정의 사용 가능 한도가 필요합니다. API 키는 필요하지 않습니다.
   runtime/codex 폴더와 LICENSE/NOTICE 등 동봉 파일을 그대로 유지해 주세요.
   Gemini: 별도 Antigravity/Node.js 설치가 필요 없습니다. 처음 로그인·연결 확인 시
   Google 공식 연결 파일을 자동 다운로드하고 무결성을 확인합니다(인터넷 필요).
   준비가 끝나면 열린 Gemini 로그인 창에서 본인 Google 계정으로 로그인하세요.
   연결 파일은 문제공방의 runtime/gemini 폴더에 보관되어 다음부터 재사용합니다.
   공식 CLI를 내부에서 실행하며 기존 계정의 서비스와 사용 한도를 그대로 이용합니다.
   별도 API 키 결제로 자동 전환하지 않습니다.
   오른쪽 AI 설정의 GPT 로그인·계정 / Gemini 로그인·계정에서 로그인,
   로그아웃, 계정 전환을 할 수 있습니다. Gemini는 함께 열리는 로그인 창에서
   처리합니다. 완료 후 돌아와 연결 확인을 눌러 주세요. 같은 PC의 다른
   Codex·Antigravity 프로그램과 로그인 정보를 공유할 수 있습니다.
   Gemini 사용 시 프로그램의 구독 상태를 지정하고 연결 확인을 누르세요.
   연결 버튼에서 해당 계정이 사용할 수 있는 모델과 사용량을 확인합니다.
   GPT 로그인 버튼을 누르면 진행 상황이나 실패 원인이 로그인 창 안에 표시됩니다.
   브라우저가 열리지 않으면 표시된 공식 로그인 주소를 복사하여 브라우저에서 여세요.
   로그인 완료 후 문제공방에서 연결 확인을 누르세요. API 키는 필요하지 않습니다.
   배포자의 로그인 정보나 구독 사용량을 함께 제공하는 프로그램이 아닙니다.
4. 시험지 PDF 또는 사진(PNG·JPG·JPEG·WEBP·BMP)을 열거나 끌어 놓으세요.
   열린 뒤 팝업에서 시험 범위를 선택하고 문제 영역을 드래그하세요.
   시험지 없이도 상단 범위 설정에서 새 시험지의 기본 범위를 편집할 수 있습니다.
   기본값인 「영역 모으기」가 켜져 있으면 여러 문제 영역을 먼저 지정합니다.
   하단에서 문제영역 설정 → 전체 인식 → 전체 검수 → 전체 풀이 생성 → 전체 유사문제 생성 순서로 진행합니다.
   「모두 자동」은 선택 영역을 확인한 뒤 원문의 인식·풀이·검토 완료·Word 저장까지 처리합니다.
   유사문제는 별도의 「유사문제 일괄생성」에서 생성·검토 완료·문서 포함·Word 저장까지 처리합니다.
   이미 완료된 단계는 재사용하고 새로 추가한 문항과 아직 끝나지 않은 단계부터 진행합니다.
   자동 실행 안내를 승인하면 정상 처리된 문항은 자동 검토 완료 및 문서 포함 상태가 됩니다.
   해결된 확인 항목은 이력·풀이 코멘트에 남기고 오류 목록에서는 정리합니다.
   실제 미해결 오류나 실패한 요청은 남으며, 완료된 결과는 전체 중지를 눌러도 보존합니다.
   전체 유사문제 생성에서는 문항별 수치 변경 / 수치·좌우 반전 / 난이도 한 단계 높이기를 선택합니다.
   새 객관식 유사문제의 선택지를 무작위로 배열하고 정답과 풀이의 선택지 참조도 갱신합니다.
   풀이에는 단계별 이유를 자세히 설명하며 옳고 그름을 묻는 문항은 틀린 이유도 설명합니다.
   총 6점의 단계별 채점기준은 적용 가능한 서술형에만 작성합니다.
   문제 탭을 끌어 순서를 바꾸면 자동 재번호되며 문제·풀이·대화 연결은 유지합니다.
   한 문제씩 즉시 인식하려면 「영역 모으기」를 끄세요.
   원문·유사문제의 「문구 수정」에서 본문·보기·선택지를 직접 고쳐 저장하거나 취소할 수 있습니다.
   문구를 고친 뒤 검토하여 문서에 다시 포함해 주세요. 기존 도형·자료는 유지됩니다.
   도형과 공통 자료의 「끌어서 이동」을 잡아 문제 위·아래 또는 (1)·(2) 사이로 옮길 수 있습니다.
   한 이미지로 합쳐진 여러 그림은 함께 이동하며, Word·PDF에도 배치 순서가 반영됩니다.
5. Word 또는 PDF 저장을 사용하세요. 문제 뒤에 빠른 정답과 상세 풀이를 함께 저장합니다.
   답지는 새 페이지에서 시작하므로 학생에게 나눠 줄 때 해당 페이지를 제외하고 인쇄하세요.
   문제와 답지 모두 2단이며 가운데 검은 구분선이 있습니다. 본문은 맑은 고딕 12pt,
   답지는 맑은 고딕 9pt입니다. 원문/유사문제 표시 여부는 저장 옵션에서 선택합니다.
   문서 출력용 Python과 필수 라이브러리가 포함되어
   별도 Python/Codex 런타임 없이 DOCX 파일을 생성합니다.
   DOCX를 열고 최종 편집하려면 Word 등 호환 문서 프로그램이 필요합니다.
   한글 HWP 저장에는 한컴오피스 한글 설치가 필요합니다. 수식은 그림이 아닌
   편집 가능한 한글 고유 수식으로 저장합니다. 파일 접근 확인창이 뜨면 직접 허용하세요.
   HWP 저장이 실패하면 실패 원인을 표시하고 복구용 Word 파일을 보관합니다.
   정답 강조용 사각 테두리(\boxed)는 한글 출력에서 생략되며 수식 내용은 보존합니다.

채팅과 빠른 실행
  빠른 실행 버튼은 기본 1문항씩 생성합니다. 채팅에서 “3개 만들어줘”처럼
  수량을 지정하면 그 개수로 생성합니다. 수치 변경 2개와 좌우 반전 1개처럼
  유형별 개수를 함께 요청할 수 있습니다. 프로그램이 해석한 수량과 결과가
  달라도 생성된 문항은 모두 저장하고 개수 안내만 대화에 표시합니다. 채팅·추가 요청창의 직접 요청은
  기본 프롬프트보다 우선하며 충돌한 조항만 해당 작업에서 제외합니다.
  저장된 규칙은 바뀌지 않으며 각 문항의 정답·풀이·검산을 작성합니다.

기본 프롬프트·시험 범위
  제작자가 조정한 규칙과 상세 풀이·채점 기본 규칙와 시험 범위 예시 5개를 포함했습니다.
  초기 범위: 중2 2학기 삼각형의 성질·사각형의 성질.
  이 범위 이전에 배운 내용을 허용하며 닮음·피타고라스 정리·삼각비는 금지.
  실제 시험 범위에 맞게 설정에서 수정해 사용하세요.

저장·업데이트
  문제·대화·수정한 규칙은 실행 폴더 안 data에 저장됩니다.
  다른 PC로 작업을 옮기거나 업데이트할 때 프로그램을 종료하고 data를 따로 백업하세요.
  새 버전은 별도 폴더에 압축을 풀고, 기존 data 폴더를 새 실행 폴더로 복사하면
  문제·대화·수정한 규칙을 이어서 사용할 수 있습니다. 기존 폴더는 확인 전까지 보관하세요.
  기본값 복원은 선택한 설정에만 적용됩니다.
  이 ZIP에는 제작자의 시험지·생성 문항·계정·대화 기록을 포함하지 않습니다.

검증 범위
  격리된 새 사용자 폴더에서 실행·PDF/이미지 열기·설정·Word 저장을 점검합니다.
  AI 자동 테스트는 모의 응답이며 친구 PC의 실제 계정/모델 호출은 첫 사용 시
  확인해야 합니다. AI 결과는 사용자가 검토해 주세요.
  Windows 코드 서명이 없는 테스트 배포판이므로 실행 시 게시자 확인 안내가
  나올 수 있습니다. 제작자에게 받은 파일인지 확인하세요.
