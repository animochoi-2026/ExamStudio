# 경원중 2025년 2학기 중간고사 24·25 세트 복구

2026-10-15. 원본의 `[24~25]`는 문제 내용이 아닌 공통 지문 문항 범위다. 두 문항의 기존 최신 revision과 공통 지문 원본을 대조하여 기존 세트 등록 기능으로 연결한다. 원본 파일·개별 발문·선택지·정답·풀이는 바꾸지 않는다.

공통 출력에는 재번호 가능한 지문 제목, 원문 조건 상자와 관찰 좌표 도형을 사용한다. 원본에 확인된 AG/AD의 이중 빗금과 E/C의 직각 표시만 유지하며 원본에 없는 평행 화살표는 표시하지 않는다. 25번의 기존 공통 제목·상자·문구·도형 노드는 공통 출력에서 제외하고 개별 발문을 보존한다. 연속된 2·3번으로 배치할 때 `[2~3]`과 도형 한 개가 출력된다. 원본 PNG/WebP는 덮어쓰거나 삭제하지 않는다.

사용자가 별도로 승인한 저장 A1의 원문 24번 다음에 25번을 추가한다. 기존 객관식과 같은 4점을 적용하여 23문항·100점에서 24문항·104점이 된다. 다른 유형과 기존 문항의 상대 순서·배점은 유지한다. 계획은 과거 계획대로 보존하고 실제 구성 집계 및 표지의 총점을 갱신한다. 버전 충돌·세트 완전성·그룹 중복·회원 권한 검사를 포함하는 기존 RPC를 사용하며 세트 등록과 모의고사 저장은 한 트랜잭션으로 수행한다. 변경 전 저장본은 무시되는 로컬 점검 폴더에 보존한다.

PDF 캐시 조회 전에 최신 세트 레지스트리를 확인한다. 뒤늦게 등록된 세트의 일부만 있는 과거 PDF는 최신본으로 내려주지 않는다. 세트 정보·버전은 출력 문서 서명에 포함된다. 조회 실패는 빈 레지스트리로 바꾸지 않는다. 기존 원본·그룹·권한 스키마와 과거 마이그레이션 이력은 변경하지 않는다.
