선택 풀이: ∠DAB=72°, ∠FAH=108°이므로 △AFH의 두 밑각은 41°, 31°이다. △FAH≡△ABC를 SAS로 보여 ∠BAC=41°를 얻고, AF⊥AB와 AK가 AC의 반대 반직선임을 이용하면 ∠KAF=49°이다. 정답은 ②.
실행 판정: 파일럿 기준: 각의 비 계산→∠FAH 계산→두 밑각의 합 계산→합·차로 41° 계산→여각 계산의 수치 처리 5단계이다. 대응각과 반직선 방향도 확인해야 하므로 기준 학생에게 누적 실행 부담이 있다.

## 핵심 판정과 한계

1. **V2 — 조립 미충족:** 단계는 3개에서 7개로 늘었으나, 숨은 두 삼각형의 대응 선택만 비자동 M3이고 나머지는 M0 적용으로 판정됐다. 연결된 비자동 M2 이상은 1개로 기존 조건 3개에 못 미친다. 실행 게이트는 새로 켜졌지만 T5 상한으로 최종 9.7은 같다. 단계를 나누라는 지시만으로 조립 게이트가 해결되지 않았다.
2. **V5 — 실행 미충족:** 36가지 전체 열거 대신 이동 조합을 좁힌 풀이를 선택해 6개 순서쌍·4단계로 판단했다. 새 기준은 ‘4단계 초과’이므로 실행 게이트는 false다. 4.2→8.4 상승은 실행 승급이 아니라 기본 티어 T0→T2 변화에 독해 승급이 더해진 결과다. 정답 6개 순서쌍은 맞지만 원시 독해 근거의 ‘잡은 뒤 시작으로 돌아가더라도’라는 표현은 원문의 ‘상대편에게 잡힌 경우’와 다르다. 이 근거 문장은 오류로 기록하고 원시 결과를 수정하거나 재평가하지 않았다.
3. **V6 — 독해 유지:** 두 눈의 합 또는 중간 꼭짓점별 풀이 모두 독해·실행이 켜져 9.7이다. 합으로 세는 경로의 기본 티어는 T2, 선택된 꼭짓점 경로는 T3이다. 기존 스코어러는 최종 티어·점수가 같을 때 route_id로 선택하므로, 선택 경로의 T3을 필수 발상 난이도로 단정할 수 없다. 정답은 7/162이다.
4. **B11 — 교사 확인 대상:** 직사각형을 먼저 판정하는 경로가 자동 적용 중심으로 평가돼 기본 T0, 독해만 더해 T2/4.5가 됐다. 이전 8.6보다 낮아졌다. 정답 ①·②는 유지되지만, 경로 선택 및 비자동 판정의 변동이 큰 사례다.
5. **B14 — 교사 확인 대상:** 상한 계산과 달성 확인을 약 5회로 세어 실행 게이트가 켜졌다. 실행량 축 E=2인데도 extreme=true라 T4/8.6이다. 요청한 임계 기준에 따라 작동했지만, 이 정도 계산을 승급할지는 교사 판단이 필요하다. 조립은 비자동 M2 이상 1개로 미발동이다.
6. **B19 — 교사 확인 대상:** 두 닮음을 이어 붙이는 경로에서 11단계를 기록했지만 비자동 M2 이상은 연결된 2개뿐이다. 조립은 미발동이고 독해·실행이 켜졌다. 대칭 보조점의 대안도 확인했다. 정답 ④(ㄱ·ㄴ·ㄷ), 9.7은 유지되며 실행 추가 효과는 T5 상한에 가려진다.

**결론:** 실행 게이트의 미발동 현상은 이 표본에서 완화됐지만 조립 게이트는 해결되지 않았다. 프롬프트만 바꿔도 경로·축 판정이 함께 달라졌으므로 점수 변화 전체를 새 게이트의 효과로 볼 수 없다. 스코어러를 바꾸거나 기대값에 맞게 원시 판정을 보정하지 않았다.
