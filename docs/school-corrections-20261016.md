# 학교별 원문 대조 보정과 상세보기 이동

시작 기준 6265c788, 설치 앱 0.4.50. 사용자 지정 8개 학교의 문항만 원본 스캔과 대조한다. 사용자 자료/이전 revision은 로컬 복구 백업과 기존 maintenance 백업에 보존하며 유료 AI와 전체 대기열 재개는 실행하지 않는다.

## 공통 코드

- 검수 문항 상세의 목록 버튼은 `schools` 시험지 목록으로 직접 이동한다. 이전/다음 문항은 기존 기능을 유지한다.
- 명시적으로 원본 대조한 선택지 열 정보는 원래 선택지 문자열과 함께 저장한다. 선택지 변경 시 오래된 열 정보는 사용하지 않는다. 웹/앱/PDF/DOCX에서 열 대응을 유지하며 분할 문항은 각 셀의 열 제목을 함께 표시한다.
- 도형의 선택적 글자 배율, 여러 줄 라벨, 선분 끝 연장 금지 및 점 표시 제어를 추가한다. 지정하지 않은 기존 도형은 기존 동작을 유지한다.
- 영역 인식은 같은 페이지의 다음 단으로 이어진 문항도 기존 continuationOf로 연결하도록 지시한다. 인쇄 근거가 있는 서술형 영역은 번호 앞에 서술형이 반복 인쇄되지 않아도 구분한다. sourceNumbering.section이 written인 정수 번호는 서술형 번호 공간에 저장한다.
- DOCX 분할 검사는 완전한 한 조각도 허용한다. 내용 범위의 연속성과 전체 포함 검사는 유지하며 잘린 한 조각은 계속 차단한다. 풀이 여백 때문에 측정 경로가 바뀐 정상 문항의 등록 실패를 해결한다.

## 지정 자료

도형·선지·번호 보정 17개 revision은 기존 본문/선택지/정답을 보존한 maintenance 경로로 등록했다. 누락 문항은 원본 확인 후 제한된 개별 복구로 처리하고 교사 검수 완료로 표시하지 않는다. 진선여중 서술형4의 다음 단 영역은 같은 문항에 연결하며 기존 별도 영역과 대기열 기록은 이력에 보존한다. 수서중 원문17과 내부 목록17, 진선여중 원문9와 내부 목록9는 다른 문항이므로 원문 번호로 대조했다.

세곡중19는 원본의 단일 정답 발문과 달리 선택지③과⑤가 모두 성립한다. 원본을 바꾸거나 임의 정답을 확정하지 않고 사용 중지/교사 검수 대상으로 보존한다.

검증: 선택지 열 대응/원문 번호/도형 표시 회귀와 단일 분할 전체 포함·잘림 거부 테스트. 배포와 실제 설치 상태는 후속 release record에 별도로 기록한다. 신규 유료 AI 인식 결과와 실제 물리 기기 출력은 이번 검사에 포함하지 않는다.
