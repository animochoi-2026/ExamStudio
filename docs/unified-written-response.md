# 객관식·서술형 통합과 출제 부족 후보 선택

2026-10-14 사용자 요청에 따라 공개 응답 분류는 객관식과 서술형이다. 기존 내부 객관식 키 `선택형`은 호환성을 위해 유지한다. 단답형·서답형·서논술형·논술형 및 기타 이름 있는 비객관식 응답은 서술형으로 해석한다. 값이 없는 자료를 임의 분류하지 않는다.

공통 `app/response-format.cjs`를 데스크톱 등록, 웹 표시와 출제, 모의고사 교체·구성에 사용한다. 서버 `bank_query.response_format`도 같은 규칙이다. 원문·과거 revision·저장된 문항의 순서와 배점을 일괄 수정하지 않는다. AI 답안 검증에 필요한 single_value/proof 등 원래 의미와 채점 기준은 유지한다.

일반 시험지의 이전 유형별 개수는 합산한다. 모의고사 이전 short/written 설정도 합산하며, 배점이 다르면 이전 배점 묶음을 보존한다. 사용자가 통합 문항 수/배점을 직접 바꿀 때 새 설정을 적용한다. 기존 출제 완료 시험지를 자동 재출제하지 않는다.

출제 실패 화면에도 공통 보충 후보 선택기를 연결했다. 지정 학교의 선택 범위 전체 후보부터 표시한다. 타학교 확대를 눌러 세부 단원을 지정해야 해당 단원의 후보를 서버에서 20개씩 조회한다. 출제 전에는 교체 대상 원문항이 없으므로 세부 단원을 명시적으로 선택한다. 후보 선택은 확정 전 출제하거나 저장하지 않는다. 적용 시 최신 후보 및 모의고사 그룹 사용 기록을 재검사하고 기존 개수·난이도 조건으로 구성한다.

마이그레이션 `20261014105033_unified_written_response.sql`은 해당 함수만 갱신했다. 익명 실행 차단, 회원·학년·그룹 권한과 최종 모의고사 저장 검사는 유지한다. 원본 문항·회원·그룹·시험지 DML, 과거 migration repair, 전체 db push는 하지 않았다.

검증: 공통 회귀 84개 및 출력 계약, 신규 통합 검사 5개와 기존 후보 검사 2개. PC 1280px/모바일 390px 실제 포인터 검증 10개 시나리오에서 이전 단답형 5개 출제, 지정 학교 47/49개 전체 표시, 타학교 20/20/5개, 취소 보존, 보충 11문항 선택 후 일반 60문항 및 모의고사 60문항씩 2종 구성을 확인했다. 기존 생성 후 교체 포인터 검사 4개도 통과했다. 합성 자료 기반 검증이며 실제 사용자 시험지를 생성·저장하지 않았다.

설치 후보 0.4.40의 별도 데이터 폴더 시작과 공통 모듈 무결성을 확인했다. 실제 설치본 0.4.39도 별도 데이터 폴더에서 시작 오류가 없었다. 사용자가 보고한 데스크톱 오류는 구체적 동작·문구가 확인될 때까지 미확인이다. 버전 변경만으로 해당 오류를 해결했다고 간주하지 않는다.

운영 반영 식별값은 release-records 및 release/canonical.json의 플랫폼별 기록을 따른다.
