공통 instructions와 [JSON Schema](schema.json)는 동일하다. 원문 JSON·이미지는 문항마다 추가한다. 저장 정답은 로컬 검증 전용이며 모델 입력에서 제외한다. 과거 자동·교사 점수, override, 이전 단계 결과, 외부 목표 점수는 입력하지 않는다. 비교용 앵커 점수는 프롬프트에 없다. 사용자가 요구한 보조선 경계의 구조 예시는 학교·문항 번호를 빼고 유지했다.

- 은행: 최소 1,266회, 3단계까지 최대 **3,798회**. 같은 단계 자동 재시도 **0회**, strict calibration 비활성.
- 외부 V1–V8: 대화에 첨부된 원본 이미지 3개의 로컬 존재 확인. 별도 8문항, 최대 24회. 학교 점수 전환 대상에는 포함하지 않음.
- 전체 상한: **3,822회**. 이것은 최대치이며 불필요한 상위 단계는 호출하지 않음.
- 구독 로그인으로 실행. 별도 유료 API 호출·API 키 등록 없음. 인증/구독 한도 공통 실패 시 중단·완료 단계 보존. 결과 불명인 호출은 자동 반복하지 않음.
- 이전 약 20.6시간은 과거 파일럿 참고치다. 새로운 정답 검증으로 상위 단계 비율이 달라질 수 있으므로 이번 완료 시간을 확정하지 않는다.
- 대상·revision은 실행 전에 고정하고 평가 중 바뀐 문항에는 오래된 결과를 적용하지 않음. 이후 새로 등록된 자료를 이번 일괄 평가에 임의 추가하지 않음.

## 이번 변경의 핵심

- 낮은 Luna 결과도 풀이·정답·원문·Schema·의존 그래프·confidence 검사 필요.
- 발견 수 최소 3개 강제 제거. 실제 비자동 선택만 분리.
- 문해력 +1 유지. 단순 조건 4개·4줄이나 모든 증명에 자동 적용하지 않음.
- 기존 수동 점수는 이번 전환에 승계하지 않지만 복구 스냅샷 보관. 이후 교사 조정 기능 유지.
- 자유 증명 등 자동 동치 확인이 불가능한 답은 통과로 꾸미지 않음. 실패율 5% 초과 시 기존 점수를 지우지 않고 전환 중단.

승인 전에는 실제 평가를 실행하지 않는다. 이 문서나 manifest 파일 생성 자체를 승인으로 취급하지 않는다.
