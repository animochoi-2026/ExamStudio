# 0.4.35 통합 릴리스

공식 기준 `0a919486c05855e018a4fc0405a93219d91ada5e`에 모인 웹과 데스크톱의 승인된 수정 사항을 같은 배포 소스로 정렬한다. GitHub main의 이전 기준은 `ee53fb267ad21f0279f6973ed71b69ea9c5d01ed`였다.

## 세션·소스 대조

- 로컬 문제생성기 세션 152건의 메타데이터를 대조했다. 자동 인식·보호 작업을 구분하고 개발 대화 9건(보관된 학습자 대화 포함)과 관련 클라우드 대화 13건의 최근 결과를 확인했다.
- 기존 worktree들의 HEAD 변경은 공식 기준에 같은 패치로 포함되어 있다. 과거 R2 준비 폴더의 미커밋 작업과 일회성 복구 스크립트는 보존하며 배포본에 복사하지 않는다.
- 별도 stored-statistics 브랜치의 집계 기능은 현재 소스에 포함되어 있다. 비공개 과거 이력과 백업 브랜치는 공개 저장소에 push하지 않는다.
- 설치 앱과 공식 소스의 학교 배분·공통 계약·출력 엔진 차이는 새 패키지로 갱신한다. 사용자 데이터는 설치 패키지와 분리한다.

## 보존 계약

HWPX 2018 내부 XML 프로필, 원본 그림 참조, 자동 정렬, A/B/C 기본 구성, 공통문항 전체 교체 및 학년 격리를 유지한다. 패키징 단위 검사의 가짜 폴더가 Git 저장소 검사를 수행하던 문제는 테스트 fixture에서 검증 호출 순서를 명시하고 실제 폼 파일을 제공하도록 수정했다. 실제 패키징의 공통 검사는 그대로 실행한다.

## 검증 범위

공통 회귀 검사 65개와 업데이트·업로드·패키징 검사 17개, 공통 출력 엔진 검사를 수행한다. 실제 ZIP 설치 및 데이터 보존 검사와 격리된 프로필에서의 앱 기동도 확인했다. 브라우저 출력 검사는 세트 조회·출력 권한 RPC, 현재 버튼명, 확대 전 배치 좌표와 워커의 폼 이미지 자산을 사용하는 fixture로 갱신했다. 출력 결과 및 오류 검증은 유지한다. 최종 배포·설치 결과와 해시는 `release/canonical.json`에 별도로 기록한다. XML/패키지 검사는 한글 2020이나 모바일에서의 실제 렌더링 검증을 대신하지 않는다.

Codex 클라우드 갱신 절차는 `docs/codex-cloud-sync.md`를 따른다. GitHub 공개와 기존 클라우드 작업의 갱신 여부를 별도로 확인한다.
