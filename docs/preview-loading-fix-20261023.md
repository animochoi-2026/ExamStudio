# 폼 변경 후 미리보기 대기 수정

사용자 승인: 구현 “시작해”, 운영 웹 “배포도 진행해”. 대명중 기출문제 복원에서 모던 미니멀 선택 후 크기 확인 메시지가 지속된다는 후속 제보를 포함한다.

## 변경

- 배치 작업 중 글꼴/그림 로딩 이벤트가 같은 배치를 다시 시작하지 않는다. 화면 이동과 새 설정 적용 시 이전 작업의 대기는 취소한다.
- 세트 조회, 문항 읽기, 글꼴과 그림 디코딩의 응답 대기를 각각 30초로 제한한다. 실패한 단계를 표시하고 배치 다시 시도를 제공한다. 실패한 배치로 저장/출력을 허용하지 않는다.
- 문항 읽기와 크기 측정 진행 수를 표시한다. 문항 선택, 원본 순서/배점, 도형, 폼 치수와 출력 계약은 바꾸지 않는다.
- 학교 선택은 기존 공식 소스에서 기본 펼침 및 범위 선택 전 학교 표시를 유지한다. 이번 검증에서 모바일/PC 초기 상태를 다시 확인했다.

## 검증

- 기준 소스의 반복 글꼴 이벤트(80ms) + 지연 문항 읽기(180ms)에서 모던 폼 배치가 5초 내 완료되지 않는 현상을 재현했다. 같은 조건에서 수정본은 완료되고 다음 단계로 이동했다.
- 390/1280px 일반/모의고사 4흐름: 학교 목록 기본 펼침, 선택 유지, 목표 평균 7.00점 유지. 일반 시험지는 세트 조회 무응답 → 시간 초과 표시 → 재시도 → 기본/모던 폼 복구를 확인했다.
- 대명중 2026년 중2 2학기 중간고사 25문항: 운영 catalog를 읽기 전용 조회하고 로컬 원본 25개 본문과 일치를 확인했다. 로컬 문항 모델과 원본 그림을 합성 저장소에 연결한 실제 웹 번들 복원에서 390/1280px 모두 25문항/100점/문제 9쪽 배치를 완료했다. 분할 문항을 포함한 원본 번호/본문을 보존했다. 기준 운영 번들도 정상 연결 조건에서는 완료했으므로 사용자의 실물 기기에서 발생한 정확한 원인은 단정하지 않는다.
- 공통 필수 84검사 및 출력 계약 통과. 대기/취소/오류 보존 단위 검사 3개 통과.
- 기존 modern-minimal-browser 검사 통과: 배점 표시 전후 위치 동일, 긴 문항 분할, 기존 폼, 계정별 폼 설정, 이미지 PDF 생성 및 native 출력 snapshot.

브라우저 검증은 합성 인증/API 응답을 사용했다. 대명중 자료 조회 이외 운영 API 호출/저장, 데이터 변경, DB migration, AI 호출은 없다. 실제 회원 로그인/서버 저장/실물 휴대폰은 검증하지 않았다. 생성 PDF 성공은 한글 2020 실기 검증을 의미하지 않는다. 상세 로그와 사용자 문항 snapshot은 무시되는 artifacts/modern-preview-fix에 보관하며 소스에 포함하지 않는다.
