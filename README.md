# 문제공방 (ExamStudio)

수학 시험지의 문제 인식, 풀이·유사문제 제작, Word·PDF·한글 출력을 위한 Windows 프로그램입니다.

**[최신 문제공방 다운로드](https://github.com/animochoi-2026/ExamStudio/releases/latest)**

## 처음 실행하기

1. 위 링크에서 `ExamStudio-버전-win32-x64.zip`을 내려받으세요. `Source code`는 실행 배포판이 아닙니다.
2. ZIP의 **전체 내용**을 쓰기 가능한 폴더에 압축 해제하세요.
3. `문제공방.exe`를 실행하세요. 실행 파일만 따로 옮기면 작동하지 않습니다.
4. 사용할 GPT 또는 Gemini를 선택하고 본인 계정으로 로그인하세요.

Windows 10/11 64비트(x64)를 지원합니다. GPT 실행 환경과 Python이 포함되어 있으며, Gemini 연결 환경은 처음 연결할 때 내려받습니다. AI 사용에는 인터넷과 본인 계정의 사용 가능 한도가 필요합니다. 한글(HWP) 저장에는 한글 프로그램이 필요합니다.

## 프로그램 업데이트

**0.4.0부터 오른쪽 AI 설정 아래 → 프로그램 업데이트**에서 새 버전을 확인하고 설치할 수 있습니다. GitHub 로그인은 필요하지 않습니다.

다운로드 파일을 검증하고 프로그램을 재시작하여 업데이트합니다. `data` 폴더의 작업·대화·수정한 프롬프트와 결과물은 유지되며, 이전 프로그램 파일은 `data/updates` 안에 백업합니다.

0.4.0 이전 버전은 이번 ZIP을 먼저 내려받으세요. 기존 프로그램을 종료하고 기존 `data` 폴더를 새 배포 폴더로 복사하면 작업을 이어갈 수 있습니다. 기존 결과물도 필요하면 함께 옮기세요. 개발본은 자동으로 교체되지 않습니다.

이 저장소는 배포 파일과 업데이트 안내를 제공합니다. 개인 시험지나 로그인 정보를 올리지 마세요.
