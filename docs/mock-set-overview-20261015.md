# 실전모의고사 문항 보기의 세트 표시 수정

## 원인과 변경

`mock-exams.js`의 `questionOverview`는 각 문항을 독립적으로 읽으면서 시험지 안의 세트 위치를 전달하지 않았다. reader의 독립 문항 기본값 때문에 모든 구성원에 공통 자료가 반복되고 원문 번호가 표시되었다. 이전 경원중 수정에서 출력 reader만 직접 검증했고 이 모달 경로를 검증하지 못했다.

모달을 열 때 현재 권한으로 세트 레지스트리를 한 번 조회하고 저장 항목에 연결한다. 세트의 완전성·연속 순서를 확인한 뒤 첫 구성원만 공통 자료를 표시하고 현재 시험지 번호로 범위를 치환한다. 구성원들을 하나의 테두리로 묶고 내부 개별 스크롤을 제거한다. 시험지 전환 중 이전 조회 결과는 표시하지 않는다. 조회 실패는 빈 후보와 구별한다.

원본 문제 상세·독립 후보 미리보기는 읽기에 필요한 공통 자료를 유지한다. 일반 편집·기출 프린트 출력 경로는 이미 세트 위치를 전달하고 있어 변경하지 않았다. 저장 데이터, 문항 순서·배점, PDF 생성 방식, 교체 정책은 변경하지 않았다.

## 검증

- `node tests/mock-set-overview-browser.cjs`: 실제 mockExams + createQuestionReader + 출력 DOM 사용. 합성 2문항 세트 2개와 3문항 세트 1개, A1/A2의 다른 위치, 1280/390px. 세트별 그림 1개, 현재 번호 범위, 발문 수, 가로 넘침 없음. 연결 실패·빠른 유형 전환도 확인.
- 같은 테스트에 무결성 해시가 일치하는 실제 경원중 24/25 원본과 등록 레지스트리를 로컬 전송으로 제공: A1 `[2~3]`, A2 `[1~2]`, 각 그림 1개. 두 크기의 실제 모달을 클릭·스크롤하고 캡처 확인. 원본 개인 자료는 무시된 artifacts 안에만 보관한다.
- `node tests/replacement-stages-browser.cjs --written`: 일반/실전모의고사, PC/모바일 후보·확대·선택·공통 교체 확인/취소·개별 교체 회귀 검사 통과.
- 세트/PDF 레지스트리 단위 검사 5개 통과.
- 운영 읽기 전용 집계: 등록 세트 3개(원문18/19, 23/24, 24/25). 공통 모달 수정이 모든 등록 세트에 적용된다. 다른 두 운영 세트의 실제 원본 화면은 직접 검증하지 않았다.

운영 로그인 계정에서 저장 모의고사를 직접 조작하지 않았다. 물리 모바일·설치 데스크톱 앱·프린터 미확인. 배포 및 공통 검사는 release-records의 이번 배포 기록으로 구분한다.
