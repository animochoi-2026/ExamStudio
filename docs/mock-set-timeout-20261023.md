# 실전모의고사 배치 중 세트 조회 시간 초과 수정

2026-10-23 운영 로그에서 `bank_question_sets_get`의 SQLSTATE `57014`와 8초 statement timeout을 확인했다. 여러 시험지를 순차 준비하며 동일한 세트 목록을 반복 요청했고, 한국어로 변환된 오류가 기존 재시도 조건에서 빠졌다.

## 수정

- 후보 스냅샷과 함께 읽은 세트 목록을 해당 출제 작업의 각 시험지 및 바로 열리는 첫 미리보기에 전달한다. 서버/저장 문서에 캐시를 저장하지 않는다. 다른 화면·새 출제·문항 또는 개정 변경·명시적 새로고침은 다시 확인한다. 문항 자료의 읽기 권한 검사는 유지한다.
- 원문 문서/번호 검색과 확정된 자식 개정 조회에 인덱스 2개를 추가했다. 함수, 권한, 세트 완전성·모호성·원문 순서 판정 및 운영 시간 제한은 변경하지 않았다.
- 원본 SQL 오류 코드·메시지 및 HTTP 상태를 보존해 일시 오류만 1회 재시도한다. 사용자 취소, 권한 오류, 데이터/배치 오류는 재시도하지 않는다. 세트 조회 재시도에서 문항 선정·저장을 반복하지 않는다.

## 필요한 검증

- 관련 Node 검사 12개 통과: 원본/번역된 오류, 1회 제한, 취소/권한 거부, 캐시 분리·개정 변경·새로고침.
- 실제 편집기와 합성 RPC를 사용한 브라우저 검사 통과: 두 시험지 출제와 첫 미리보기까지 세트 조회 1회, 시간 초과 1회 발생 시 총 2회, 권한 거부 시 1회 후 중단. 후보 조회는 반복하지 않음.
- 운영 DB의 같은 SQL 실행 계획: 4034.154ms → 28.065ms, shared buffer hit 79304 → 1228. 한 번씩 비교한 측정값으로 모든 접속의 응답시간을 보장하지 않는다.
- 운영 소유자와 교사 인증 문맥에서 변경 전후 반환 JSON 일치, 각각 세트 5개. 익명 호출은 42501 거부 유지.
- 실제 사용자 시험지 생성, AI 호출, 설치 앱 변경은 수행하지 않았다.

운영 웹 적용과 최종 자산 검증은 별도 release record에 기록한다.
