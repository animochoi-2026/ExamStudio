# 검수함 원본 PDF 페이지 표시

문항 crop을 우선 표시한다. crop이 없는 영역은 같은 source ID로 연결된 verified 원본 PDF와 실제 페이지 번호를 사용한다. 원본 파일을 RLS로 다시 확인하고 기존 bank-storage 서명 URL의 HTTP Range로 필요한 64 KiB 범위만 읽는다. 전체 본문 200 응답은 거부한다. PDF.js 6.3.289와 폰트/문자맵은 같은 출처의 고정 런타임이다.

761px 이상에서만 지연 로드한다. 페이지 좌표가 있는 경우 테두리로 표시하고, 문항 이동 시 요청을 취소하고 이전 이미지를 제거한다. 모바일에는 기존 한 열 인식 문항만 표시한다. 소스 파일이나 페이지 정보가 없는 경우 원본 없음 안내를 유지한다.

## 확인한 범위 (2026-10-15)

- 참조 파일/페이지 식별과 HTTP Range/권한 오류 단위 검사 2개 통과.
- 실제 로컬 브라우저에서 PDF.js로 8,392,743바이트 합성 PDF의 2쪽을 표시할 때 69,671바이트만 읽음.
- 1280/1024/768px에서 각각 동일한 두 패널 너비, 390px에서 원본 패널 숨김 확인.
- 실제 버튼으로 crop 우선, 좌표 유무, 2→3쪽 이동, 원본 없음, 모의 접근 거부와 재시도 표시 확인.
- 합성 자료만 사용했으며 운영 원본 및 회원 데이터는 변경하지 않음.
- 운영의 실제 회원 간 접근 차단, 원본 PDF 부분 읽기, 새 배포 자산은 별도 인수 확인 대상이며 이 로컬 검사를 운영 검증으로 간주하지 않음.
