# 0.4.38 대기열 잔여 오류 수정 후보

운영 0.4.37 재실행 후 보이는 세 시험지에서 풀이 보류 3건, 업로드 실패 3건을 확인했다. 운영 데이터와 앱은 이 후보 준비 과정에서 수정하지 않았다.

- 청담중 2023 2학기 중간 서술형 3: 채점기준의 “금지된 삼각비 … 인정하지 않는다”를 실제 사용으로 오인. 명시적 금지 안내만 구별하고 usedConcepts 및 다른 문장의 실제 사용 검사는 유지한다. 현재 원문·범위의 저장 풀이에 한해서 해당 진단만 다시 계산한다. 교사 승인이나 다른 오류는 변경하지 않는다.
- 청담중 2023 2학기 기말 서술형 3: 이전 좁은 범위로 작성된 solutionDraft 때문에 원문 확인 제한이 다시 발생. 인식 결과를 현재 범위로 새로 푸는 것은 허용하되 기존 draft를 완성 풀이로 재사용하지 않는다.
- 청담중 2024 2학기 기말 16: 공통 자료를 담은 crop에 15번도 포함되어 원문 번호가 `15, 16`으로 인식됨. 영역 탐지의 단일 대상 번호를 인식 지시에 전달한다. 실제 인쇄 번호가 다르면 추측하지 않는다. 기존 혼합 인식은 대상 한 문항 재인식이 필요하다.
- 청담중 2023 기말 13: 빈 observedDiagram에서 renderer가 null을 반환했는데 Buffer.from(null)을 실행. 도형이 없는 문항은 그림 자산을 만들지 않으며 잘못된 도형 참조 오류는 유지한다.
- 청담중 2023 중간 업로드: 시간 초과로 끝나지 않은 부모 revision을 자식의 기준으로 사용함. 같은 계정·문항·저장소의 기존 대기열 부모를 순서대로 완료하고, 서버에서 이미 완료한 부모는 재사용한다. 충돌·결과 불명·계정 변경은 자동 통과하지 않는다.
- 청담중 2024 기말 15: 세트 수동 확인 제한이 대량 등록을 막음. 대량 대기열만 제안 정보를 미검수 metadata로 보관해 등록한다. 확인된 세트로 만들거나 공통 자료를 삭제하지 않으며, 세트 확인 전 독립 문항 선발은 기존 incomplete set 검사로 차단한다. 일반 개별 업로드는 기존 확인 절차를 유지한다.

검증: 신규/인접 회귀 14개, 로컬 PostgreSQL 연동 신규 2개 통과. 로컬 DB fixture에 세트 조회 함수가 없어 빈 registry 읽기만 fixture로 제공하며 등록·commit은 실제 로컬 DB를 이용한다. 기존 queue 통합 검사 1건의 범위 기본값 기대 실패는 0.4.37에서도 확인되며 완화하지 않았다. 실제 실패 export snapshot에서 printAssets 결과 0개 정상, 저장된 중간 서술형 3의 scope/program 재검사 통과를 확인했다. 실제 AI 재호출·사용자 프로젝트 변경·운영 설치는 별도 적용 단계다.

2026-10-14 적용: 원본 그림 사용을 명시한 경우 재작성 도형이 없다는 진단만 해소하며 다른 검수 사유를 보존한다. 0.4.38 표준 ZIP 설치, 6건 복구 및 72개 최신 서버 등록본 확인을 완료했다. GPT-6.1 High 실제 호출은 총 3회이며 구형 런타임 모델 확인 실패는 추론 전에 중단됐다.
