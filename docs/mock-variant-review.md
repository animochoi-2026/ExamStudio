# 시험지별 교체와 공통자료 그림 중복 보정

2026-10-15. 사용자 요청에 따라 문항 보기 화면은 A1(없으면 첫 생성 시험지)부터 열고 시험지별 선택만 제공한다. 전체/공통/개별 필터는 제거했다. 현재 시험지의 저장 순서대로 문항을 읽으며 선택 변경 시 이전 목록을 즉시 지우고 이전 비동기 응답을 버린다.

교체 확정 시 두 시험지 이상에 사용된 문항이면 시험지 이름과 번호를 표시하고 전체 교체 의사를 확인한다. 취소는 데이터 변경 없이 후보 화면에 남는다. 확인 후 기존 서버 중복 검사와 `mock-round-edit.replace`를 사용해 모든 사용 위치를 한 번에 반영한다. 개별문항은 해당 위치만 변경한다. 기존 형식/범위/중복/세트 제약과 순서/배점을 유지한다.

`mock-round-edit.distribution`은 실제 저장 문항 ID 기준 공통문항 고유 개수, 전체 배치 개수, 시험지별 공통/개별 개수와 개별문항 단원별 개수를 계산한다. 생성 완료 시 기존 자동 보충 안내와 한 팝업에 표시하며 `문항 배치 구성 보기`에서 다시 확인한다. 저장/복원/교체 후 현재 문항으로 다시 계산한다. 학생용 페이지에 관리 안내를 추가하지 않는다.

그림 중복은 원본의 공통자료 이미지와 동일한 인식 관찰 도형을 동시에 출력하던 웹 경로에서 발생했다. 원본 한 영역, 같은 인식 버전, 변경되지 않은 이미지 좌표 도형, 원본 공통자료 안에 전체 도형이 들어 있고 해당 그림을 정상적으로 읽은 경우에만 별도 관찰 도형 출력을 생략한다. 작성된 재구성 도형, 구조 레이아웃, 여러 원본 영역, 일부만 포함한 자료, 그림 읽기 실패는 생략 대상으로 보지 않는다. 원본/인식 데이터는 변경하지 않는다. 표본은 원본 조건·선택지·정답·풀이가 이미 맞아 AI 재인식을 실행하지 않고 원본 대조와 출력 중복 수정을 수행했다.

웹 PDF 요청의 문서 서명에 `outputRenderingVersion: source-material-once-v1`을 포함한다. 저장 목록 다운로드도 같은 문서와 표시 버전을 전달해 예전 중복 그림 PDF를 재사용하지 않는다. 운영 서버의 기존 권한/다운로드 검사와 캐시 교체 규칙을 유지한다. 과거 PDF 일괄 생성이나 저장소 정리를 실행하지 않는다.

검증: 합성 DB의 일반/모의고사 형식 필터 및 배분 독립 저장, 1280/390px 실제 클릭으로 공통 교체 취소/확인/개별 교체와 결과 집계, 최초 자동 구성/저장 복원, PDF 생성/재사용을 검사했다. 운영에서 읽은 표본 파일 해시와 일치하는 저장 바이트를 실제 reader/무손실 증명 검증으로 읽어 수정 전 그림 2개와 수정 후 1개를 양쪽 화면 크기에서 확인했다. 실사용 모의고사 변경/저장, 운영 원본 데이터 변경, 유료 AI 호출은 하지 않았다. 물리 휴대폰·프린터·설치 데스크톱 출력은 미확인이다.
