## 반영 내용

1. 시험지 만들기의 학교 선택 목록은 높이 제한과 내부 스크롤 안내를 제거했다. 검색·선택·순서·접기는 유지하고 페이지 전체로 스크롤한다.
2. 일반 시험지에서 목표 점수를 직접 입력하면 `profile.driver=target`으로 저장한다. 상·중·하 추천 비율은 참고 표시이며 문항 수 제약이 아니다. 실제 문항 난이도 점수의 산술평균을 목표에 가깝게 선택한다. 비율을 직접 변경한 경우의 기존 비율 출제와 기존 저장본은 유지한다.
3. 일반 자동 채우기 완료 팝업에 실제 선택한 문항 전체의 학교·난이도 구간·점수별 개수와 실제 평균을 표시한다. 이전 실패 구성에서 몇 개만 추가한 것처럼 오해하지 않도록 “자동 채우기 후 구성”이라고 표시한다.
4. 시험지 상세에서 목록으로 돌아오면 필터·페이지·스크롤을 보존한다. 홈을 방문하면 학교/복원 목록 필터를 초기화하고 이전 history 상태가 필터를 되살리지 못하도록 목록 세대를 기록한다. 학년별 저장 키는 유지한다.
5. 서초구의 신동중/신동중학교를 학교 선택·조회·출제에서 신동중으로 표시한다. 후보 요청에는 두 원래 이름을 포함하며 기출프린트 선택 키는 하나로 묶는다. 원본 학교 레코드, source_id, revision_id, 문항 및 시험지 자료는 수정/삭제하지 않는다. 명시적으로 다른 지역인 학교의 기출프린트 키는 합치지 않는다. DB 병합/이름 변경 migration은 없다.
6. 실전모의고사의 목표 점수 직접 입력에도 같은 평균 기준을 적용한다. 자동 출제에서 형식·선택 범위·기존 문항·원본 기준 중복 제외·세트·기존 타학교 서술형 보충 개수를 유지한다. 공통문항 조정 경로는 목표 평균 오차를 키우지 않는다. 자동 구성 팝업에서도 실제 학교/난이도 구성과 평균을 보여 주고 참고 비율 차이를 보충 실패로 표시하지 않는다.

## 선택 알고리즘의 범위

기존 배분기로 문항 수·형식·학교·단원 배분의 가능성을 먼저 확인하고, 실제 점수 합의 목표 오차를 줄인다. 숫자 없는 문항을 임의의 0점/5점으로 계산하지 않는다. 세트는 완전한 단위로 교환한다. 사용자가 명시적으로 선택한 보충 문항은 필수로 포함하며, 그 선택에 따른 학교 배분은 자동 최적이라고 보고하지 않는다.

작은 후보군은 제한된 전수 탐색을 사용한다. 큰 후보군은 제약 벡터가 같은 문항/세트 및 두 단위 조합의 교환을 사용하며 전체 후보에 대한 전역 최적해를 보장하지 않는다. `profileSummary.optimization`에 방법·탐색 한도·현재 배분 내 최적성 여부를 남긴다. 목표 점수가 불가능하면 선택 가능한 실제 평균을 표시한다. 기존 문항의 평가 점수나 평가 정책을 바꾸지 않는다.
