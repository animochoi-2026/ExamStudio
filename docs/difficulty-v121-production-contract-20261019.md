# v1.2.1 운영 전환 계약 검토

사용자는 2026-10-19에 1,266건의 실제 프롬프트/normalizer/입력 해시 및 14건 review envelope를 보존하는 예외 방식, 최신 데스크톱 정책, 구형 점수 저장 차단, 운영 점수 원자적 전환을 승인했다. AI 재평가와 원문 수정은 금지한다.

## 의도적인 저장 계약 변경

신규 catalog INSERT와 자동 평가 변경은 최신 공통 정책의 완료 또는 최종 실패 기록을 요구한다. 기존 점수의 단순 조회와 같은 원문의 향후 교사 조정은 계속 허용한다. 과거 결과는 별도 고정 집합으로만 활성화한다.

`tests/group-operations.test.cjs`는 모든 최신 migration을 적용한 뒤 신규 catalog를 삽입한다. 새 저장 정책에 맞춰 이 합성 입력에 현재 버전의 평가 기록만 추가했다. 기존 점수 배열, 필터별 기대값, 그룹/권한/보관/삭제/만료 관련 모든 assertion은 변경하지 않았다. 검사 제거, trigger 비활성화 또는 정책 우회는 없다. 두 테스트가 최신 migration을 포함해 통과했다.

별도 `tests/difficulty-v121-production.test.cjs`에서 1,266건 일괄 전환, 배포 게이트, 동시 검수 충돌 시 0건 적용, 트랜잭션 rollback, 구형 점수 변경 거절, 향후 교사 조정, 수정 이후 rollback 차단, 권한 제한을 검증했다. 데스크톱 라우팅/캐시/기존 평가 범위 20검사도 통과했다. 실제 AI 호출은 0회다.

보존 계약 파일 해시는 위 의도적 입력 계약 변경에 대해서만 갱신한다. 소스 기준 갱신은 설치 또는 운영 활성화 완료를 뜻하지 않는다. 설치/운영 실측 상태는 별도 기록한다.
