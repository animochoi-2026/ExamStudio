# 무학중 저장 기출프린트 시각 자료 복구

대상은 52문항 저장본의 5번(2025 중간 원문 14), 42번(2023 중간 원문 15), 48번(2023 중간 원문 21)이다. 사용자 신고와 원본 시험지의 해당 문항 crop을 직접 대조했다.

- 5번: 구조 도형 안의 보기 번호와 label-only choices가 모두 출력됐다. 원본 보기 그림을 사용하고 확인된 그림 속 번호만 표시한다.
- 42번: 건물이 포함된 원본 삽화 대신 점만 있는 재작성 도형이 출력됐다. 원본 삽화로 교정한다.
- 48번: 여러 보기 도형을 가진 구조 데이터가 있지만 auto 모드의 복합 특징 조건을 충족하지 않아 일반 출력에서 누락됐다. 원본 보기 전체를 구조 모드 그림으로 표시한다.

`layoutDocument.choicePresentation`은 원본을 확인한 시각 자료에만 명시한다. 공통 `structured-layout.forOutput`은 활성 구조에 해당 그림이 존재하고 숨김 상태가 아니며, 모든 choices가 확인된 ①~⑤ 번호만인 경우에만 출력 복사본의 중복 번호를 제거한다. 저장 choices, 본문, 정답, 풀이, 원문 배점, 분류·평가·검수값은 보존한다. 일반 텍스트 선택지는 제거하지 않는다. 원본 PNG는 문제 본문 전체가 아닌 실제 그림·보기 영역만 사용한다.

기존 문항 ID는 유지하고 정상 유지보수 revision/백업 경로를 사용한다. 해당 저장 시험지에는 사용자 요청한 세 revision만 CAS 저장한다. 다른 49문항의 순서·배점·revision과 출력 설정은 그대로 유지한다. 새 revision은 PDF 서명을 변경하므로 예전 PDF를 최신으로 재사용하지 않는다.

코드 검증: 출력 중복 제거/반례 2개 및 기존 구조 출력 10개 통과. 데이터 적용·운영 PDF 확인 결과는 최종 작업 기록에 별도로 남긴다.
