# 학교 목록 모바일 UI

공통 메뉴 박스의 세로 내부 여백을 줄이고 입력·버튼의 최소 터치 높이 44px을 유지했다. 인쇄 지면은 변경하지 않았다. 원본 목록의 별도 문항 검수 버튼을 제거하고 별도 검수 메뉴와 기존 제목 이동은 유지했다.

`source-browser.js`는 기존 `bank_source_list_page`의 schools 모드 전체 total을 사용한다. papers 모드에서는 같은 필터로 학교 total을 한 번 조회하며 페이지 이동에는 재사용한다. 목록의 길이로 전체 학교 수를 추산하지 않는다. 검색 입력 즉시 기존 숫자를 지우고, 실패와 0건을 구분한다. 학교별 관련범위는 서버가 반환한 필터된 해당 학교 전체 exams의 question_count 합계다. 서버·데이터 변경 없음.

`school-list-ui.js`의 공통 문구·스크롤 안내를 목록과 시험지 생성 학교 선택에 적용했다. 안내는 스크롤 영역 바깥에 있고 실제 남은 스크롤이 있을 때만 표시한다. 기존 지역 제목·한국어 정렬을 유지한다. 모바일 640px 이하에서 필터 4열, 300px 미만에서 2열 대체 배치다.

검증: 관련 단위 7개, 390px 숨김 Electron 대표 화면에서 한 줄 배치·44px 높이·가로 넘침 없음·지역 구분·필터/0건/실패·끝 안내·페이지 이동 시 학교 count 재조회 없음 확인. 테스트 모듈 번들 수정 후 최종 통과. 스크린샷 및 Computer Use 0회. 운영 읽기 전용 API: 전체 32학교(페이지 10), 강남구 16학교, 대명중/대왕중 각각 관련범위25. 실제 업로드·PDF·Google 조회·AI 실행 없음.
