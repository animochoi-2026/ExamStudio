# 실전모의고사 모바일 후속 수정

사용자는 앞선 6개 수정(`3c6d45a`, `docs/site-logic-fixes-20261023.md`)과 아래 사항을 함께 운영 웹에 반영하도록 승인했다. 공식 기준 `1054c44`를 포함하는 기존 격리 worktree에서 앞선 변경을 보존했다.

- [x] 시험지 추가 팝업의 A형 이름은 줄바꿈과 flex 축소를 막아 B/C형처럼 가로로 표시한다. 긴 설명은 줄바꿈할 수 있다.
- [x] 문항 위 이동·교체 버튼은 모바일 높이 28px로 줄였다. 드래그로 이동하고 누르기만 해서는 위치 선택창을 열지 않는다. 키보드 Alt+방향키와 이동 되돌리기는 유지한다.
- [x] 되돌리기 버튼은 한 줄로 표시하고, 최초 모의고사 미리보기는 모바일에서도 실제 미리보기 영역 폭에 맞춘다. 사용자 확대·축소 값은 유지한다.
- [x] 모의고사 자료 준비가 일시적인 통신·시간초과·이미지 디코딩 오류로 실패하면 이미 선정된 문항으로 최대 한 번 재시도한다. 후보 조회/자동 출제/저장은 다시 실행하지 않는다. 세트·무결성·권한·지면 초과 오류는 자동 재시도하지 않는다.
- [x] 배치 오류를 일반 문구로 덮지 않고 실패한 시험지와 실제 준비 오류를 표시한다. 취소 신호는 준비 단계에도 전달한다. 모든 시험지의 준비가 성공하기 전에는 회차에 결과를 적용하지 않는다.

## 검증

- 수정 전 관련 14개, 수정 후 앞선 6개 변경을 포함한 관련 21개 Node 검사 통과. 웹 번들 및 diff 검사 통과.
- `node tests/mock-preview-followup-browser.cjs`: 합성 API와 실제 UI로 390px 터치/1280px 마우스 드래그 확인. A/B/C 이름 한 줄, 모바일 버튼 높이 28px, 드래그·되돌리기, 단순 누르기로 이동창이 열리지 않는 것 확인.
- 두 번째 시험지의 세트 조회에 통신 실패를 주입하면 동일 후보 스냅샷으로 한 번 복구한다. 반복 통신 실패는 두 번째 실패로 종료하고 원인을 표시한다. 무결성 오류는 재시도하지 않는다. 브라우저 예외 0개.
- 브라우저 검증 스크립트의 초기 시도는 실제 버튼 이름과 다른 테스트 선택자, 화면 아래 고정 버튼에 가려진 드롭 위치 때문에 실패했다. 실제 표시 이름과 보이는 드롭 위치로 교정했으며 최종 전체 시나리오가 통과했다.

사용자가 올린 오류에는 하위 원인이 없어 모던 미니멀 폼 자체의 결함으로 확정할 수 없다. 이번 확인은 재현 가능한 일시 실패의 복구와 상세 오류 표시를 검증한 것이다. 실제 회원 데이터로 해당 오류를 재현하거나 실물 휴대폰·한글 2020·출력 파일을 새로 검증하지 않았다. AI 호출/DB 변경/설치 앱 변경은 없다. 필수 공통 검사와 배포 자산 검증은 공식 배포 경로에서 수행하고 별도 release record에 기록한다.
