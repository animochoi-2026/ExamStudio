## 배포·복구

현재 소스에서 `node scripts/build-bank-web.cjs <공개설정JSON> <빈출력폴더>`로 생성한 파일만 Pages에 직접 배포. 시험 fixture가 들어간 preview-site는 운영 배포 금지. 운영은 final-site. 이전 고정 ZIP workflow·manifest는 백업 후 제거하고 수동 source build로 교체. GitHub Actions는 원격 반영/실행하지 않았으며 BANK_PUBLIC_CONFIG repository variable과 검토 SHA가 필요하다.

앱은 검증된 Electron 런타임에 최신 app/공통 출력 scripts를 적용하고 같은 Windows 사용자에서 기존 프로필을 복사한다. 이전 경로에서 시작하는 로컬 JSON 경로만 새 위치로 바꾼다. 인증 파일은 그대로 보존하며 키/내용은 기록하지 않는다.

복구 시 앱 종료 후 `문제공방-보존-20261011/app-before`와 `profile-before`를 사용하되, 새 앱에서 편집한 자료가 생겼다면 현재 data/r2-current를 먼저 보존하고 변경분을 대조한다. 과거 프로필로 무조건 덮어쓰지 않는다. 웹은 직전 배포 ID를 최종 배포 기록에 보존한다. R2 저장소/DB는 변경하지 않음.

메일 남은 조건: 발송용 서비스 API 인증과 허용된 발신 주소. 운영 Edge Secrets 조회에서 MAIL/SMTP/RESEND 관련 설정 없음. 초대 메일의 BANK_RESEND_API_KEY/BANK_INVITE_FROM도 미설정. 기존 R2/DB 키로 메일 인증을 대체하지 않으며 임의 가입·유료 추가·실제 발송은 하지 않음.
