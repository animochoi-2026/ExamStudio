## 구현 및 확인

- [x] 기출문제 복원: 내부 스크롤 박스를 없애고 현재 페이지의 모든 시험지를 표시. 페이지 이동 유지.
- [x] 원본 시험지 검수: 미해결 인식 경고, 실제 검사 실패, 사용 중지, 버전 충돌 등 업로드 확인 사유가 있는 문항 우선. 오른쪽 모든 문항 버튼, 대상 없으면 전체 표시. 원문 순서와 저장 검수 상태 유지.
- [x] 직전대비 기출프린트: 학교명을 가로로 줄바꿈하는 사각형 버튼. 선택 색상과 키보드 포커스, 단일 선택 유지.
- [x] 시험지 생성 시험범위: 펼친 메뉴가 높이 제한 없이 페이지 아래로 이어짐.
- [x] 부족 문항: 지정한 학교에서 보충 / 자동채우기 / 타학교 문제로 확대. 세로 동일 너비 버튼. 지정 학교 보충은 학교·난이도·단원 배분 제한을 해제. 자동채우기는 배분 차이를 줄이는 유한 근사 탐색. 타학교 버튼은 필터를 즉시 열며 선택한 타학교 후보를 재확인 후 사용.
- [x] 문항찾기·검수함·원본 검수 카드: 기존 미리보기 렌더러로 본문과 그림 표시. 보이는 카드부터 동시 2개 로딩, 실패 시 다시 불러오기. 원본/그림 참조는 변경하지 않음.
- [x] 간헐적 Failed to fetch: 읽기 RPC의 일시적 연결 오류만 한 번 재시도, 한국어 오류 안내. 저장·삭제·AI 재호출 없음. 이전 장애의 구체적인 네트워크 원인은 사진만으로 확정하지 않음.
- [x] 홈 용어 도움말 제거, 킬러 문항 아래 난이도 평가기준 팝업. 현재 운영 v1.2.3 문서와 실제 표시 규칙에 근거한 설명: AI T0/T1 하, T2/T3 중, T4 상, T5 킬러. 교사 숫자 조정은 기존 3/8/9 경계. 기존 홈의 오래된 숫자 경계 문구도 함께 정정. 로그인 전 홈에도 동일 적용.
- [x] 학교·시험지: 관련범위 버튼 제거, 시험지 목록을 내부 스크롤 없이 표시.
- [x] 홈 집계: 계정·공간·학년·권한별 메모리 캐시 5분, 메뉴 이동/포커스만으로 삭제하지 않음. TTL 만료 시 기존 값 먼저 표시, 갱신 실패 시 유지. 집계 새로고침과 데이터 변경 시 무효화. 접근 권한 확인 유지, 로그인 전 전체 집계 보존.

## 구성 보존

명시적 부족 문항 복구 외의 자동 출제 알고리즘은 유지한다. 복구도 접근 권한·시험범위·금지 개념·중복 제외·객관식/서술형 수·세트 연속성을 유지하며, 불가능하면 기존 시험지를 보존한다. 원래 배분 목표와 실제 구성은 분리해서 표시한다. 설치 앱·서버 schema·회원·대기열·평가 점수는 이번 웹 수정 범위에 포함하지 않는다.
