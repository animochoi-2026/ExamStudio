# 세트 문항 공통 출력·인식 (2026-10-15)

세트는 선택·이동·제외·교체 시 묶음으로 처리하며 문항 수와 배점은 각 구성원별로 계산한다. 공통 지문/그림은 첫 구성원에 한 번 표시한다. 공통 지문에는 번호 범위가 필수이며 은행에서는 원문 번호, 시험지에서는 실제 배치 번호를 사용한다.

## 구현

- question-sets.cjs: 빠진 세트 제목 보완, 원문 범위 재번호, 확인된 공통 원본 그림 crop 재사용. 원본 바이트 무변경.
- question-replacement / replacement-model / mock-round-edit: 같은 문항 수·각 자리 형식의 세트 전체 교체. 자리별 점수/여백/순서 보존. 공통으로 사용한 모든 유형 교체 확인·취소 유지.
- bank_set_replacement_candidates: 기존 회원·카탈로그 가시성·모의고사 그룹 사용 이력을 재사용한다. 지정 학교 전체 세트, 타학교는 최대 20개 구성원(세트가 잘리지 않도록 묶음 단위) 조회. 서버 최종 저장 세트/중복 검사는 기존 함수를 유지한다.
- question-set-recognition / task-schemas / rules / workflow: 기존 인식 요청에서 명시 범위와 공통 노드/그림 참조를 분리한다. 정확한 같은 출처의 모든 짝 문항과 공통 텍스트가 확인된 경우만 자동 연결하며, 불명확/누락/중복 식별은 확인 대기로 남긴다. 교사 검수 승인을 생성하지 않는다.
- question-set-registration / desktop: 업로드 전 명시 세트 자동 연결, 서버 저장 결과 불명 시 읽기로 회복하며 재전송하지 않는다. 업로드 전 로컬에서도 완전한 인식 세트는 함께 선택한다.
