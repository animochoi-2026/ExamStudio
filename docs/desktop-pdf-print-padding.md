# 데스크톱 PDF 마지막 빈 페이지 보정

웹 하단 내비게이션용 body 여백이 Electron 인쇄 HTML에 들어가 마지막 빈 페이지를 만들었다. 인쇄 미디어에서 html/body padding과 scroll-padding을 0으로 지정한다. 본문 폼 여백과 답지 두 열 규칙은 유지한다. 로컬 PDF 캐시 renderer 버전을 올려 기존 빈 페이지 파일을 재사용하지 않게 한다.

실제 Electron 출력 검사에서 2문항의 긴 상세풀이 120단계와 끝 표시를 모두 추출했고, 모든 페이지의 텍스트 존재 및 반복 답지 여백을 검사했다. 페이지 전체 래스터 변환은 추가하지 않았다.

검증 도구의 종료된 stdout 파이프에서 발생한 EPIPE 오류도 확인했다. 해당 임시 프로세스만 종료했으며 설치 앱과 업로드 대기열은 건드리지 않았다. 도구는 EPIPE만 처리하고 다른 오류는 계속 보고한다. 수정 후 PDF 생성 및 정상 종료를 다시 확인했다.

소스 버전은 0.4.46이다. 패키징·설치·설치본 실제 워크플로는 별도의 검증 기록이 있어야 완료로 간주한다.
