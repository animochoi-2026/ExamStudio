# 부족 문항 보충: 시험범위와 학교·난이도 필터

2026-10-14. 기준 소스 d415620. 출제 후 한 문항 교체와 출제 전 부족 문항 보충은 서로 다른 조회 흐름이다.

## 원인과 변경

- 이전 보충 창은 교체 대상이 없는데도 타학교 조회에 세부 단원 하나를 요구했다. 후보 선택 후 기존 난이도 개수를 고정하여 하 난이도 부족을 중·상 선택으로 해소할 수 없었다.
- 일반 시험지와 실전모의고사의 공통 `supplement-picker.js`에서 세부 단원 선택을 제거했다. 부족 난이도가 있으면 지정 학교·현재 시험범위의 다른 난이도 후보를 먼저 모두 표시한다. 지정 학교 전체 난이도 보기로 같은 난이도 후보도 확인할 수 있다.
- 타학교 확대는 학교(전체 또는 한 학교)와 하·중·상 복수 선택 필터를 연다. 확정 전에는 타학교 문항 API 호출이 없다. 필터 수정 후에도 다시 확정해야 조회한다. 현재 시험범위 전체를 서버에서 필터링하고 20개씩 반환한다. 상에는 기존 출제 분류에 따라 9점 이상도 포함한다.
- 운영 화면 검사에서 내부 학년 코드 `m2`와 저장된 출처 학년 `중2`의 불일치로 후보가 0건이 되는 오류도 확인했다. 공통 학년 표시 함수를 사용해 서버 조회 전에 정규화했다. 브라우저 테스트도 실제 화면과 같은 `m2` 설정으로 변경했으며, 운영 화면 검사는 실제 후보가 1개 이상 표시되어야 통과하도록 강화했다.
- `bank_replacement_candidates`의 `purpose=supplement` 경로만 범위를 확대한다. 기존 출제 후 교체는 원래 문항의 같은 세부 단원 규칙을 유지한다. 원본 ID 제외, 그룹 보관 회차 제외와 교체 직전 서버 검사는 유지한다.
- 선택한 보충 문항은 모두 포함해야 성공한다. `supplement-plan.cjs`는 부족한 난이도 슬롯만 선택한 다른 난이도로 옮기며, 총 문항 수·객관식/서술형 수·시험범위·세트·배점은 바꾸지 않는다. 나머지 자동 구성에는 기존 선택기를 쓴다. 실제 난이도 점수나 원본 분류는 수정하지 않는다.
- 실전모의고사의 공동 배분·교환에서도 선택 문항을 제거하지 못하게 검사한다. 결과에 변경 전후 난이도 개수를 표시하고 저장된 시험지에는 적용 내역을 남긴다. 허용 조건에 맞지 않는 선택은 오류로 알리고 기존 시험지를 보존한다. 명시한 균등 학교 배분 등 추가 조건을 임의로 풀지 않는다.

## 검증

- 공통 검사 84개 및 기존 출력 계약 통과. 기본 Python 환경에 docx가 없어 첫 출력 검사가 중단되었고, 기존 제공 런타임을 지정한 재검사에서 통과했다. 보존된 빌드 스크립트와 계약 기대값은 변경하지 않았다.
- 추가 및 인접 검사 11개: 하 2개 부족 → 중·상 직접 선택, 선택한 ID 유지, 같은 난이도 타학교 보충 시 원비율 유지, 범위·형식·배점 보호, 두 모의고사 공통 배분, 그룹 격리·늦은 충돌, 20/20/5 서버 페이지.
- PC 1280px·모바일 390px 브라우저 14개 시나리오: 두 화면의 출제·보충·취소, 선택 체크의 페이지 간 유지, 확정 전 타학교 조회 0건, 문항 미리보기·실제 포인터 클릭, 2개 부족분 적용 후 출제 완료.
- 기존 출제 후 교체 4개 시나리오 통과. 이는 로컬 합성 DB에서 실행한 검사이며 운영 회원·시험지를 만들지 않았다.
- 운영 서버 기존 회원 권한 조회: 청담중 사각형 범위의 중·상 25개, 타학교 하 19/19개·중 20/72개·상 20/54개 응답, 학교 한 곳 지정 시 그 학교만 반환. 운영 문항·회원·그룹·저장 시험지 DML 없음.
- 서버 migration `20261014114129_supplement_scope_filters.sql`만 적용. 로컬 파일명과 원격 이력 일치. 익명 실행 불가, 인증 실행 가능, 고정 search_path, 회원 gate·그룹 사용 기록·최종 중복 검사 확인. 과거 이력 repair/db push 없음.
- 운영 화면 검증과 웹 배포 식별값은 `release-records/supplement-scope-20261014.json`에 별도로 기록한다. 설치 데스크톱 앱은 변경하지 않는다. 실제 휴대전화 기기의 터치와 사용자 저장 시험지 수정은 미실행이다.

## 제한

원래 문항 교체의 같은 단원 제한은 그대로다. 이 변경은 부족 문항 보충에 적용한다. 선택한 후보로 형식·대단원 배분·학교 균등 등 나머지 조건을 만족하지 못하면 무조건 출제하지 않고 선택 변경을 안내한다. 현재 제한된 탐색이 가능한 모든 수동 조합을 증명하는 것은 아니다.
