# 실전모의고사 시안 운영 통합 — 2026-10-23

사용자가 승인한 실전모의고사 시안의 구성/결과 화면을 실제 출제 편집기에 연결했다. 홈과 일반 시험지 만들기의 흐름은 변경하지 않는다. 시험지 폼 설정의 중복 배점 표시 체크박스만 제거하고 미리보기의 배점 설정은 유지한다.

## 변경

- 시험지 구성은 시험지별 범위 목록과 회차 공통 설정 요약으로 나누고, 결과 화면은 시험지 선택과 실제 인쇄 미리보기로 나눈다. 모바일에서는 위아래로 배치한다.
- 기존 교육과정 트리를 사용해 소단원까지 선택한다. A/B/C 기본값과 사용자 설정, 기존 생성 문항을 유지한다.
- 난이도·출처 학교·폼·문항 수를 기존 컨트롤과 모델로 편집한다. 새 출제는 기존 자동 배분과 같은 그룹 보관 회차 제외 규칙을 사용한다.
- 미리보기에서 실제 기존 교체 후보 조회/검증과 공통문항 전체 교체를 사용한다. 이동·교체 버튼을 문항 위에 나란히 배치하고, 끌기/위치 선택/키보드 이동 및 마지막 이동 되돌리기를 제공한다. 이동은 현재 시험지의 세트와 수동 순서를 보존한다.
- 인쇄 설정에는 회차 이름, 글씨·그림 크기, 배점 표시, 폼 선택·편집을 제공한다. 편집 도구는 인쇄·파일 출력에서 제외한다.

## 확인

- 공식 기준 `4ef128cf39785314c128d97ef57e0eef98f7d5ed`를 포함하는 격리 worktree에서 작업했다.
- 필수 Node 계약 84개를 순차 실행해 모두 통과했다. 최초 병렬 실행의 3000후보 성능 검사만 10.417초로 제한을 초과했고, 별도 집중 실행에서는 통과했다. 제한과 검사는 수정하지 않았다.
- 번들 Python으로 기존 출력 호환 계약을 통과했다. 물리적인 한글 2020 실행 검증은 하지 않았다.
- 실제 UI/출제 코드를 합성 문항/API로 실행: 두 시험지 생성, 목표 평균 7.00, 소단원 선택, 드래그 및 위치 선택 이동/되돌리기, 타학교 후보 교체, 폼 설정의 중복 배점 항목 제거 및 미리보기 배점 유지 확인.
- 운영 회원 로그인/실제 서버 저장을 재실행하지 않았고, 운영 데이터 변경·AI 호출·DB migration·설치 앱 변경은 없다.
