# 문제공방 0.4.21

현재 사용 중인 웹과 Windows 앱을 공식 기준본으로 확정한 버전입니다.

- 공동 문제은행과 웹·데스크톱 연동
- 난이도·시험범위·단원 비중을 반영한 시험지 자동 구성
- 세부 문제 유형 기반 중복 최소화와 기존 문항 유형 정비
- 페이지 간 문항 이동, 긴 문항의 다음 단·페이지 연속 배치
- 초5·초6·중1~중3·고1~고3 시험범위
- DOCX·PDF·편집 가능한 HWPX 직접 저장과 HWPX 호환성 개선
- 시험지 폼, PC 배치 미리보기, 대기열과 마지막 불러오기 폴더 기억

Windows ZIP에는 실행에 필요한 런타임이 포함됩니다. 기존 사용자 데이터와 프로필은 포함하지 않습니다.
웹 ZIP은 현재 운영본과 동일합니다. 복구 방법은 소스의 `release/README.md`, 파일 검증은 `SHA256SUMS.txt`를 참고하세요.
