## 구성과 배정

기존 구성기는 각 시험지의 엄격 조건 충족에 실패하면 결과를 적용하지 않고 필수 수동 보충으로 넘어갔다. 또한 같은 회차 내 공통문항 사용을 최대화했다. 새 초기 구성은 별도 mock-auto-fill 모듈과 worker의 automatic 모드로 분리했다. 기존 모델은 저장된 공통문항/이전 기능과 검증을 위해 보존했다.

같은 학교·범위·형식·난이도 일치, 같은 학교의 난이도 완화, 타학교 서술형의 목표 난이도, 타학교 서술형의 난이도 완화 순으로 비용을 부여한다. 객관식 타학교 후보는 서버와 클라이언트 모두 자동 구성 대상에서 제외한다. 실제 후보가 없는 것은 0문항/미충족으로 표시하고 조회 실패는 오류로 처리한다.

형식별 슬롯과 후보 전체의 증가 경로 매칭으로 순차 배정의 후보 독점을 피한다. 후보가 이미 배정되어 있어도 다른 시험지로 재배정할 수 있다. 고정 슬롯에서 최대 문항 수와 최소 완화 비용을 구하고, 객관식/서술형 사이의 난이도 슬롯 교환으로 더 나은 공동 구성을 탐색한다. 세트는 원자적으로 유지하며 세트 배정 탐색은 최대 128개 상태로 제한한다. 전체 다차원 문제에서 전역 최적이라는 주장은 하지 않는다. 제한 도달 여부는 sharing.bundleSearchLimited에 기록한다. 동일 ID/입력의 순서만 바꿔도 같은 결과가 나오도록 정렬한다.

## 서버와 동시 저장

bank_mock_auto_candidates는 기존 회원/학년/사용 가능/같은 그룹 사용 기록을 재사용한다. 서버 원본 식별자를 반환하고, 현재 회차의 유지 문항 원본과 타학교 객관식을 조회 단계에서 제외한다. 학교 표시명이 모호하면 자동 합치지 않고 오류로 안내한다. 접근 권한은 authenticated에만 있으며 비회원은 함수 내부에서도 거부한다.

bank_mock_save의 기존 그룹 트랜잭션 잠금·버전 검사·원자적 저장을 유지한다. 새 회차 및 자동 구성 이력이 있는 회차는 여러 시험지 사이의 동일 원본 중복을 거부한다. 자동 정책 표시를 제거한 요청도 새 회차나 기존 자동 회차에서 우회할 수 없다. 과거 공유 방식으로 저장된 회차의 공통문항 편집은 유지한다.

명확한 PT409 그룹 중복 응답만 자동 복구한다. 충돌하지 않은 문항을 보존하고 새 후보 스냅샷으로 충돌 문항을 채운 뒤 전체 문서를 다시 저장한다. 반복 충돌은 마지막에 충돌 문항을 미충족으로 남겨 저장을 시도한다. 총 최대 4회 저장 시도이며 반복 충돌/통신 실패/문서 버전 충돌은 성공으로 가장하지 않는다. 데이터베이스 트랜잭션이 실패하면 시험지/연결 정보의 부분 저장은 남지 않는다.
