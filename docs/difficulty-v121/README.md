# 난이도 v1.2.1 — 실행 전 준비

사용자 통합 요청서: [원문 전체](request.md). 과거 파일럿은 재현 가능하도록 그대로 보존한다.

이 점수는 실제 학생 집단의 정답률이 아니다. 정규교과 약 70% 이해·기억, 계산 실수, 조건 유지의 어려움, 발상 생성 취약이라는 기준 학생에 대한 construct-based predicted difficulty다. 개념 수·풀이 길이·산술 길이를 발상 난이도와 동일시하지 않는다. 실제 응시 자료는 empirical difficulty로 별도 저장해야 한다.

## 준비된 범위

- 별도 `app/difficulty-v121` 스코어러·엄격 Schema·정답 대조·라우팅·입력 식별·전환 계획.
- literacy +1 및 증명 형식 (d), 전형적 수선과 숨은 정삼각형 보조선 경계. 과거 발견 최소 3개 강제는 제거.
- 낮은 Luna도 유효성 검사를 통과해야 확정. 두 번째 정상 결과가 최종이며 평균·투표 없음.
- 원시 JSON 불변, 독립 분기 max / 대체 경로 min, 기본 T5의 게이트 기록.
- 기존 Codex 구독 실행 어댑터에 명시적 v1.2.1 프로필 추가. 과거 프로필의 동작·해시 유지. API 키로 전환하지 않음.
- 운영 최신 대상 1,266문항 / 52시험지를 읽기 전용으로 확인하고 ID·revision 목록을 비공개 artifacts에 저장.
- 프롬프트 승인용 세 문서와 동일 Schema·SHA256 생성. 생성 스크립트에는 AI·DB 쓰기·배포 경로가 없음.

## 아직 실행하지 않은 범위

실제 모델 호출, 전체 복구 스냅샷·원문 준비, 전체 staging 평가, 서버 트랜잭션 전환 어댑터, 웹 표시·데스크톱 자동 평가 연결 및 패키징/배포는 완료 상태가 아니다. 운영 기존 점수·수동 교정·원문·대기열·설치 앱은 유지된다. `cutover.cjs`는 순수 전환 계획이며 DB 원자적 전환을 수행한 것이 아니다.

전체 실행 전에 [1단계](stage-1-prompt.md), [2단계](stage-2-prompt.md), [3단계](stage-3-prompt.md)와 [실행 승인 범위](approval.md)를 사용자에게 제시한다. **요청서 Part 1 §10 / Part 2 §20에 명시된 프롬프트 승인이 필요**하다. 요청서의 운영 전환 승인은 조건부로 이미 주어졌으므로 중복 승인 게이트를 만들지 않는다.

## 정답 검증의 경계

코드는 모델의 solution_validated 값을 신뢰하지 않는다. 객관식 번호·선지 내용, 정규화된 동일 답, 정확한 유리수 동치를 대조한다. 임의의 자유서술·증명·기호식 동치나 단위 변환을 검증했다고 주장하지 않는다. 현재 자동 대조가 확인하지 못한 값은 answer_equivalence_unverified 등으로 실패 처리한다. 단순 문자열 일치도 풀이 전체의 수학적 증명을 기계 검증한 것은 아니다.

전체 전환은 미완료 없음·공통 오류 없음·실패율 5% 이하·유효한 결과 구조·시험 버전 일치·복구 스냅샷·acceptance 통과가 전제다. 실패율이 높다고 검증을 느슨하게 만들거나 과거 정답/난이도를 새 모델 입력에 힌트로 넣지 않는다.
