# 신동중 2026 2학기 중간고사 난이도 평가 요청서

## 대상

- 학교: 신동중
- 시험: 2026년 2학기 중간고사
- 범위: 문제은행에 등록된 해당 시험지의 전체 문항

## 평가 기준

4차 파일럿까지 적용된 최신 프롬프트를 사용한다:
- 기준 학생: 70% 이해, 계산 실수, 조건 3개 이상 시 망각
- 게이트 예시: 3차 선정 예시 (assembly 7개, literacy 7개, execution 6개)
- 조립·실행 강화 지시: 4차 추가 지시 (분해 강제, 학생 기준 실행 판정)

`prompt_hash`는 4차와 동일하면 재사용하고, 변경되면 새로 기록한다.

## 실행 방법

- ChatGPT 구독제로 문항당 1회씩 평가한다.
- 문제은행에 등록된 문항 ID 순서대로 실행한다.
- 결과는 별도 영역에 저장하고 기존 운영 점수를 덮어쓰지 않는다.
- 실패 문항은 `score=null`, `status="failed"`로 기록한다.

## 결과 보고

문항별로 다음을 보고한다:
- 문항 번호, 최종 티어/점수
- 기본 티어, 발동 게이트 목록
- 선택된 경로의 핵심 발견 요약

시험지 전체에 대해:
- 티어별 분포 (T0~T5 각 몇 문항)
- 게이트별 발동 횟수
- 평균 점수, 최고/최저 점수 문항

## 주의

- 교사의 수동 점수가 있으면 비교용으로만 사용하고, AI 평가 입력에는 넣지 않는다.
- 원본 배점(시험지 점수)은 난이도와 무관하게 보존한다.
- 이 평가는 파일럿 연장선이다. 운영 점수 교체는 별도 승인 후 진행한다.
