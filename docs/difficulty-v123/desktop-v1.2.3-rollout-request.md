# 데스크톱 v1.2.3 후속 적용 요청서 — 생성만

이 문서는 실행 승인이 아니다. 대상은 로컬 검증된 v1.2.3 공통 계약 코드이며 기존 정상 결과와 사용자 데이터·프로필·대기열을 보존한다.

적용 전/후 소스 commit, 웹/Edge/앱 asset hash, 되돌릴 패키지, 운영 검증 범위를 기록한다. 본 작업에서는 설치·배포 미실행이다.
